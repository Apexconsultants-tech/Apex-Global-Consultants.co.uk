# Image and video licences

Every image or video on the site must have a row here. `npm run check:placeholders` reads this
file: any row whose licence column starts with `PLACEHOLDER` blocks a production deploy.

When you replace a file, keep the same filename (or update the content file that points to it),
then change its row: source URL, author, licence, date downloaded and the edits made
(crop, light brand-colour grade).

**Never use:** images of real people presented as Apex staff or clients unless they are; images
with visible third-party logos; anything without a licence that allows commercial web use.

**Suggested free sources:** Pexels (Pexels Licence), Unsplash (Unsplash Licence), Pixabay
(Pixabay Content Licence). All allow commercial use without attribution, but record them here.

**Brand grade:** apply a light, consistent grade (lift shadows slightly, cool white balance,
5–8% overlay of #0d5ea3 in soft light) so photos sit naturally with the logo colours.
